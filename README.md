# Fahrtenbuch – Der Riesebyer

Web-App für iPhone und Android: zeigt das Fahrtenbuch aus der Fahrerkarte-App.

- **Keine Daten in diesem Repository.** Hier liegt nur der Programmcode.
- Die Fahrten liegen **verschlüsselt** (AES-256-GCM, Schlüssel per PBKDF2 aus deinem Passwort)
  in einem **privaten** Repository und werden erst auf dem Gerät entschlüsselt.
- Zugang über einen GitHub-Schlüssel, der nur dieses private Repository **lesen** darf.
- Zugangsdaten bleiben nur auf dem jeweiligen Gerät.

Installieren: Seite im Browser öffnen → iPhone: Teilen → „Zum Home-Bildschirm“, Android: Menü → „App installieren“.
